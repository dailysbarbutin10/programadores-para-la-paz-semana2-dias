El login permite identificar a un usuario antes de darle acceso a una aplicación. Algunas rutas deben estar protegidas porque contienen información privada o funciones administrativas que no deben estar disponibles para cualquier persona. La autenticación ayuda a controlar quién puede ingresar y qué acciones puede realizar. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad. De esta manera se protege la privacidad y la seguridad de los usuarios.

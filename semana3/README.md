Semana 3 - Programadores para la Paz

En esta actividad trabajé los conceptos básicos de Git y control de versiones.

Contenido

Respuestas de selección múltiple
Explicación de conceptos (Repositorio, Commit, Push)
Reflexión sobre la importancia de Git

Aprendizajes

Aprendí a usar comandos como git add, git commit y git push para guardar y subir mis avances a GitHub.

También comprendí la importancia de llevar un registro de cambios en un proyecto.

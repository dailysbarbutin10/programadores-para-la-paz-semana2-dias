El comando whoami muestra el nombre del usuario que tiene iniciada la sesión en el sistema. Esto permite identificar qué cuenta está ejecutando las tareas o administrando el servidor.

El comando uname -a muestra información detallada del sistema operativo, como el nombre del sistema, versión del kernel, arquitectura y otros datos técnicos. En Windows PowerShell este comando puede no estar disponible porque es propio de Linux y Unix.

Conocer la información del sistema es importante para administrar servidores, verificar configuraciones, solucionar problemas y asegurar que las aplicaciones sean compatibles con el entorno donde se ejecutan.
